# 03 - IntelliJ - Stdlib

Bienvenido al primer proyecto del curso Programacion Orientada al Objeto (UCN).

## Descripcion

Este proyecto dibuja un lienzo lleno de puntos al azar usando la libreria `stdlib.jar` (StdDraw).

## Requisitos

- Java 21 LTS o superior.
- Libreria `stdlib.jar` en la carpeta `libs/`.

## Estructura

```
src/    Codigo fuente
libs/   Librerias externas
out/    Clases compiladas
```
